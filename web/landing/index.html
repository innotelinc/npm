The edge layer you can own.

Keep routing and TLS simple, visible, and recoverable without handing your edge configuration to a hosted control plane.

🌐

Reverse proxy

Forward domains, redirections, streams and custom Nginx policies from one admin surface.

🔐

TLS termination

Use Let's Encrypt or custom certificates and attach them to the hosts that need them.

👥

Access lists

Apply optional HTTP authentication and allow/deny controls before traffic reaches an app.

💾

Recoverable state

Back up the database, NPM configuration and certificate material together.

⏱️

Scheduled backups

Run nightly snapshots with rolling retention, then download them for independent storage.

⚠️

Explicit restore

Validate an archive and confirm a destructive restore before replacing live edge state.

The EdgeOps layer of the stack.

NPM Edge owns routing and TLS at the boundary; Cerulean owns DNS and trust lifecycle, Authentik owns identity, Infisical owns secrets, and applications own their data.

🛡️

NPM Edge

Proxy hosts, TLS, access lists and generated Nginx configuration.

🗃️

MariaDB

NPM users, hosts, certificates, settings and audit metadata.

💾

backup-ui

Database + /data + Let's Encrypt snapshots and restores.

Local BIND when bundled.

Cerulean starts this complete NPM Edge component only when BIND_MODE=local and NPM_MODE=local. Remote-BIND deployments use an external NPM instance instead.
